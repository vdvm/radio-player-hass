# Radio Player

Offers radio stations to Home Assistant: choose a station, and the app
gives the stream URL and what is playing, so that Home Assistant can play
it on a speaker.

## Installation in Home Assistant

1. In Home Assistant, navigate to **Settings** → **Apps** → **App Store**.
2. Click the three dots in the top right corner and select **Repositories**.
3. Add repository URL: `https://github.com/vdvm/radio-player-hass`
4. Install **Radio Player**, check the configuration and start it.
